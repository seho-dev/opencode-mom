# Backend Runtime and Desktop Lifecycle

## Overview

Crate root for configuration persistence, group projection, resource discovery and mutation, deletion protection, and desktop lifecycle. Domain modules perform operations; `commands/` exposes IPC handlers, while `lib.rs` owns shell initialization and shutdown. `http_server.rs` owns the application-wide MOM HTTP listener and private `mom-http.json`, including network settings (`port`, `allowLan`) and shared authentication (`auth.tokenVerifier`), not just listener settings. MCP Proxy uses this authentication and owns no separate credential. `lib.rs` merges the listener-independent `ProxyService::router()` and shuts HTTP and proxy down concurrently. HTTP settings and MCP publications run in owned async tasks so cancelling an IPC waiter cannot interrupt disk-to-memory completion or listener restoration.

Paths in this table are relative to `src-tauri/src/`.

## Key Files

| Responsibility | File | Description |
| :--- | :--- | :--- |
| Shell lifecycle | `lib.rs` | Builds Tauri, installs shell plugins, manages ConfigPaths/PowerService/IslandService/ProxyService, routes tray then island window events, guards shutdown with an atomic barrier on RunEvent::ExitRequested, and shuts services down on RunEvent::Exit. |
| HTTP listener | `http_server.rs`, `http_server/auth.rs` | Owns private `mom-http.json`, shared Bearer authentication, serialized rebinds/key rotations, and bounded graceful shutdown. |
| Local diagnostics | `logging/`, `commands/logging.rs` | Owns opt-in JSONL recording, bounded writer controls, retention, safe filtering and the independent logging preference. |
| Manual updates | `updates.rs` | Reads native platform, checks the fixed public GitHub latest-release API, and opens only predefined project pages. |

## Conventions

- **Toolchain**: Keep main crate MSRV 1.90/edition 2021 and CI/release 1.96.0; `../native/macos-helper` retains MSRV 1.77.2 and separate formatting/check/test/Clippy gates. Fetch its locked dependencies before the first parent build; `../build.rs` builds it offline.
- **Lint policy**: Keep `../Cargo.toml` correctness/implicit-unsafe denials and undocumented-unsafe/redundant-clone warnings; run `cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets --locked -- -D warnings` on macOS/Windows. Explain unsafe invariants with local `// SAFETY:` comments; fix warnings, not blanket allowances or pedantic/nursery/unwrap/missing-docs restrictions.
- **Initialization**: Resolve production paths once with `ConfigPaths::from_environment` in `lib.rs`; initialize the captured local service target before PowerService/Island. Invalid private target config keeps management available but service operations fail closed; handlers reuse captured paths.
- **Logging lifecycle**: Initialize local logging from `state.loggingEnabled` without making storage availability a startup requirement. Record only catalogued events and fixed summaries; business operations must not propagate log failures. Stop producers and attempt a bounded writer shutdown after other services stop. The worker owns rotation, clear and query controls, while operation generations prevent disabled or earlier recording periods from leaking into a later enable.
- **HTTP failure isolation**: Manage HTTP initialization as `Result<Arc<HttpServer>, AppError>` independently of desktop setup. Initialization failures preserve the source files and keep HTTP closed; HTTP-dependent IPC returns the stored error, while unrelated desktop commands remain available. Listener bind/start failures are logged without aborting startup. Shutdown skips unavailable HTTP and still drains Proxy.
- **HTTP authentication**: Persist only `auth.tokenVerifier` alongside `port`/`allowLan`; settings DTOs remain `{ port, allowLan }`. Return a newly rotated raw key only once from the rotation command, never through settings/state DTOs, proxy serialization, errors, or logs. Missing top-level `auth` triggers one-time adoption of a valid legacy proxy verifier or publication of explicit null. Explicit HTTP auth, including null verifier, wins; invalid relevant migration data or failed publication prevents listener startup. Proxy credentials are migration input only and disappear on proxy saves.
- **HTTP transitions**: Shared middleware checks Host, Origin, and Bearer on every route/method before handlers, and binds responses to cancellation epochs. Commit rotation before revoking the old epoch, drain proxy owners/sessions with admission closed, then reopen under the serialized HTTP runtime lock. Keep fresh proxy request snapshots blocked until queued creation permits and existing owners drain; queued legacy creation rechecks cancellation before spawning and after publication. Accepted settings/rotation operations outlive canceled IPC waiters; unchanged running listener settings do not revoke sessions. Cleanup failure keeps admission closed while preserving committed settings and the returned rotation key. Listener, authentication, and proxy epochs inherit their permanent shutdown token, so shutdown closes admission before waiting on runtime locks and cannot be undone by a pending rotation. Modern stdin request writes are cancellation-aware and execution-timeout bounded; cancel notification writes share the one-second acknowledgement deadline before owner kill/reap.
- **Update safety**: Use bounded blocking HTTP/timeouts without credentials/redirects; compare only stable `vX.Y.Z`/`X.Y.Z` numerically. HTTP 404 means no stable release; malformed/network/rate-limit failures remain errors. Never install updates or accept arbitrary API/browser URLs.
- **Project links**: Validate `repository`/`releases` before building native opener commands; pass fixed URLs as arguments without shell interpolation and check launch status. Tests inspect commands without running an opener.
- **Tests**: Module tests use `tests.rs` submodules, explicit `#[path]` safety/remote suites, or inline tests in `tray.rs`; public filesystem workflows live in `../tests/app.rs` and `../tests/resources.rs`.
