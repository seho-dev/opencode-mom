# Native Island Window Contracts

Paths in this table are relative to `src-tauri/src/island/`.

## Key Files

| Responsibility | File | Description |
| :--- | :--- | :--- |
| Native window | `window.rs` | macOS public `NSScreen` safe-area discovery, public window policy, main-thread-local native transition slot and `NSAnimationContext`/`NSWindow.animator()` frames with completion readback; no runtime class replacement or global input monitors. |
| Transition guards | `transition.rs` | Pure serial/generation/native-window identity guards, one active/latest pending lifecycle, duration selection and final-frame verification. |
| Non-key hover | `hover.rs` | Public `NSTrackingArea` with a separate main-thread owner for non-key hover, weak notification/cache references, window-lifetime teardown and pure tracking-policy tests. |
| Window geometry | `geometry.rs` | Pure bounded compact/peek/expanded frames and shared finite frame acceptance in AppKit logical coordinates, with geometry tests. |

## Conventions

- **Explicit views**: Only explicit `compact` (all-screen default)/`peek`/`expanded` chooses view, never snapshots/status/refresh. Sizes are `max(notchWidth + 112, 200)` × `max(topInset, 28)`, 400 × `topInset + 132`, and 560 × 520; clamp to screen at the shared top/notch-center anchor and symmetrically clamp edge-notch compact width to retain its empty safe gap. Paint continuous black, not a notch cutout; no-notch uses menu-bar fallback/richer compact text without growth. Compact/peek clear messages, never pending requests.
- **View requests**: Preserve async lowercase enum-to-void `set_island_view { view }`; capture enabled generation before `on_main`, return its oneshot receiver, and await outside main/cache/TLS. Grow retains authoritative old view until final readback; only current explicit expansion focuses and peek never focuses/orders front. Compact/blur/close immediately cache compact, clear selection, and emit empty `island:collapsed` before shrink without session writes.
- **Transition ownership**: One main-thread-local slot owns one active/latest pending request, each capturing enabled generation, increasing serial, and native pointer/window number. Pending replacement resolves safe superseded errors; active supersession finishes its animator but excludes readback/success/focus/rollback, so reversal waits at most ~220 ms. Register before possibly immediate AppKit completion; callbacks release only their token, never new slots/windows. Disable/close/destruction drop both receivers, using weak per-window identity rather than labels; reconnect invalidates results/receivers, retains active animation until completion, then reconciles instantly. Never hold cache/TLS RefCell borrows across native calls/emissions/callbacks/awaits.
- **Native animation**: Use public `NSAnimationContext.runAnimationGroup_completionHandler`/`NSWindow.animator().setFrame_display(frame, true)` with RcBlock; grow 0.22 s, shrink 0.19 s, then main-thread origin correction/final readback before commit/focus/resolve/emit. No immediate legacy setFrame_display_animate readback, overlapping animators, timers, observers, class replacement, or animation frameworks. Startup/unchanged/display placement/current Reduce Motion use instant path; query `NSWorkspace.accessibilityDisplayShouldReduceMotion()` per transition without watchers. Real resized bounds control InVisibleRect hover/hit tests, never invisible expanded areas.
- **Content notifications**: Changed/SSE/message emissions are generation-guarded content only, never placement/focus/order-front/snapshot fetches. During animation move/focus never corrects frames or starts animators; actual screen/DPI changes set one dirty bit for later instant reconciliation. Idle move/DPI/focus correction is instant/nonfocusing; explicit Focused(true) reentry never recursively resizes, and unchanged frames are not rewritten.
- **AppKit thread**: AppKit calls stay on the native main thread. Use public safe-area selectors only when present; fallback below the menu bar.
- **Initial display**: Initial display uses public `NSWindow.orderFront`, not Tauri `show()` (which makes macOS windows key); focus is requested only by explicit expansion.
- **Hover tracking**: Install one content-view `NSTrackingArea` with `ActiveAlways | InVisibleRect | MouseEnteredAndExited | MouseMoved` and separate NSObject owner emitting only pointer notifications, never focus/view/API/actions. Track real resized bounds; repeated compact moves recover missed entry while peek emits boundaries only. Retain owner/view/area in main-thread-local storage, detach before owner release on replacement/close/shutdown/destroy; weak cache/notifications avoid service/AppHandle cycles, and disabled/expanded/retired callbacks are ignored. Never use global monitors/timers/overlays/responder replacement/runtime class mutation; WebKit tracking may be key-only.
- **Placement readback**: Restore public `NSMainMenuWindowLevel + 2`/`CanJoinAllSpaces | FullScreenAuxiliary | Stationary | IgnoresCycle` only when different. Shared finite predicate accepts |X delta| ≤0.5 logical point and exact Y/width/height before writes/correction/readback; accepted quantization never repeats setFrame/setFrameOrigin or changes ideal notch anchor/metadata. Correct unacceptable origin after changed frames, read NSWindow.frame, and reread after initial orderFront; reject nonfinite/vertical/size/larger-X mismatches. Log only phase/mode/window/level, requested/actual rects/maxY, NSScreen.frame.maxY (not visibleFrame), top/X deltas, requested_exact/requested_matched; positive screen-minus-actual top gap means below edge. Existing move/DPI/focus events recheck without timers; keep odd-notch regression (X 655.5→655.0, Y 942, 400×170, top gap 0) session-free. Level/pure tests prove neither bypass nor AppKit attachment/hover; rebuild/restart for product readback.
- **Frame diagnostics**: Debug overwrites temporary `opencode-mom-island-native-frame.log` with latest readback/PID and geometry/window metadata only, never sessions/messages/credentials; release logs only stderr, and unchanged frames never write diagnostics.
- **Tracking diagnostics**: Debug logs only options/native bounds/window flags/boundary view/connection/running count, never snapshots/session IDs/paths/messages/credentials. Compilation/mock events do not prove non-key AppKit delivery; restart the rebuilt app for manual hover acceptance.
- **Platform acceptance**: Declare Tauri transparency's `macOSPrivateApi` on the base Cargo dependency for tauri-build validation; it has no non-macOS effect. This is not NSPanel; manually accept fullscreen Spaces/notch hit tests/focus/display/wake. Reposition on expansion/focus/move/DPI, never timers or a dedicated wake observer.
