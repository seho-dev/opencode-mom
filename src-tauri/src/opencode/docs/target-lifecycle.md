# Local Service Target and Transport Lifetimes

Paths in this table are relative to `src-tauri/src/opencode/`.

## Key Files

| Responsibility | File | Description |
| :--- | :--- | :--- |
| Service target | `target.rs` | Captured private path/registration/directory, atomic saves with Unix 0600 plaintext or Windows current-account DPAPI credentials, normalized loopback URLs, password-retention rules, revisions and monitor transition guards. |
| Managed transport | `transport.rs` | Crate-private shared transport: validated registration, Basic auth, health identity checks, optional CLI bootstrap, bounded HTTP pages and credential-private async RequestBuilder; imports existing usage paging types/helpers. |

## Conventions

- **Target authority**: Initialize `target` before power/Island; missing private config selects Shared, invalid/unreadable/nonregular/oversized fails closed without crashing management. Fixed URLs accept only HTTP literal 127.0.0.1/[::1] with positive explicit port or exact localhost normalized without DNS; reject credentials/path/query/fragment/remote/shortened/numeric loopback/fallback/explicit bootstrap. Status never bootstraps.
- **Target credentials**: Persist backend-only endpoint/credential outside AppConfig in `opencode-service.json`; Unix requires account-owned regular 0600 plaintext ≤8 KiB, Windows numeric-byte current-account DPAPI encryptedPassword with file ≤32 KiB/ciphertext ≤8 KiB, no plaintext fallback, and fail-closed decryption. Keep Shared registration separate; never expose passwords in DTOs/errors/logs/events. Neither protects compromised accounts/same-account processes/admins; Windows-native DPAPI/ACL acceptance remains unverified on this macOS host.
- **Temporary credentials**: Wrap owned target-file reads, serialized target bytes, and decrypted password bytes immediately in `protected_data::SecretBytes`; parse through `&bytes.0` so all return paths wipe the temporary buffer. This does not wipe long-lived selection strings or serializer-internal allocations.
- **Target saves**: Use create_new owned UUID temporaries/atomic publication and sync final Unix directory, treating post-commit sync failures as private warnings. Null URL clears Shared/password; omitted retains only unchanged normalized URL, empty clears. Transition also guards PowerService::set/IslandService::set_enabled inside native dispatch; validate/prepare/persist/publish then infallibly invalidate, leaving monitors unchanged on preparation/persistence failure. Lock transition -> monitor effects/shared/cache -> target state write, dropping state write before commit; no native/network/await under guards, restart readers/native work only after release and before five-second probe. Stale/unavailable post-save probes return disconnected committed status, never save failure; ordinary status/read revision checks fail closed. Bootstrap/reload/Island writes reserve RAII under transition+revision, release before network/await/native dispatch, and make saves busy; blocking workers retain reservation even if async caller drops.
- **Bootstrap fallback**: Only Shared may bootstrap missing/unreachable/identity-mismatched registration; invalid/auth/HTTP errors never bootstrap. CLI candidates stop after successful spawn even when bootstrap fails. The resolver checks existence, not executable validity.
- **Registration trust**: Read regular `opencode/service.json` ≤8 KiB under absolute XDG_STATE_HOME or captured ConfigPaths home `~/.local/state`, never inferred config parents. Require UUID/positive PID/bounded valid major-2 semver/nonempty bounded password/explicit-port HTTP literal 127.0.0.1 or [::1]; uninitialized runtime fails closed, and tests inject runtimes/paths, never live registration.
- **Managed identity**: Use Basic user opencode only with passwords; passwordless fixed endpoints send no Authorization for health/read/reload/async, with no Bearer/UI-pairing/401/403 fallback or UI proxies. Disable proxies/redirects/retries; parse object `/api/info` with positive PID/bounded valid V2, requiring exact Shared registration PID/version or fixed probed identity. Pin endpoint/auth/identity/revision and recheck health before writes; server-side support is required to prevent external restart between check/dispatch. Info reachability proves neither protected access nor a reason to restart on CLI mismatch.
- **Island transport**: Initial reservation/connect/health/bootstrap runs in existing spawn_blocking; async write preparation clones pinned Snapshot Arc and reserves there, never polling transition/sleeping on async workers. RAII covers fresh health/request/body completion; dropped waiters do not cancel started blocking work, unclaimed results release, and blocking bootstrap retains reservation to completion. Subsequent requests/health/chunks stay async/cancellation-owned, with no detached writes or automatic retries/withdrawal claims for possibly accepted POSTs. Keep credentials inside transport, share five-second write-health/dispatch deadline, and cap bodies/retained snapshots at 2 MiB.

## Backend Integration

### Publication and Lifecycle Rules

- **Local service target**: Persist endpoint/backend-only credentials outside AppConfig in `opencode/target.rs`; Shared uses validated registration and optional bounded bootstrap, fixed literal loopback V2 has neither fallback nor bootstrap, and status never bootstraps. Active/catalog/reload/usage/power/Island share `opencode/transport.rs`; target saves and power/Island enablement share a mutex, prepare guards before persistence, invalidate only after publication, and wake/reconnect outside it before probing. Preserve preferences/authorization and disabled state; active writes/bootstrap/initial authorization may return `busy`. Serialize power effects against commit; never hold transition across network/authorization/native-dispatch waits, and acquire it only inside Island native dispatch.
- **Service credentials**: Unix requires account-owned regular 0600 plaintext `opencode-service.json` ≤8 KiB; Windows uses numeric-byte current-account DPAPI `encryptedPassword` (file ≤32 KiB/ciphertext ≤8 KiB), never plaintext fallback, and fails closed on decryption errors. Keep Shared registration separate; never expose passwords in frontend DTOs/events/errors/logs. Neither protects against account compromise, same-account processes, or administrators; Windows-native DPAPI/ACL acceptance is unverified on this macOS host.
